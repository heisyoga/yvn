# Adi Yoga

Personal portfolio showcasing selected projects, experience, skills, and contact information.

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

Set `GEMINI_API_KEY` in `.env` to enable the portfolio chatbot. To receive contact form submissions, configure `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`. `TELEGRAM_THREAD_ID` is optional.

## Build

```bash
npm run build
npm start
```
